# Deprecated functions in inlabru

Some of these functions may still attempt to do their job, but will be
removed in a future version.

## Usage

``` r
input_eval(...)

evaluate_inputs(...)

gmap(...)

gm(...)

ibm_linear(...)

bm_mesh_B(mesh, B)

bru_mapper_mesh_B(...)

row_kron(M1, M2, repl = NULL, n.repl = NULL, weights = NULL)
```

## Arguments

- ...:

  Usually passed on to other methods

- mesh:

  Object supported by a
  [`bru_mapper()`](https://inlabru-org.github.io/inlabru/reference/bru_mapper.md)
  method.

- B:

  a square or tall basis conversion matrix

- M1:

  A matrix that can be transformed into a sparse Matrix.

- M2:

  A matrix that can be transformed into a sparse Matrix.

- repl:

  An optional index vector. For each entry, specifies which replicate
  the row belongs to, in the sense used in
  [`INLA::inla.spde.make.A`](https://rdrr.io/pkg/INLA/man/inla.spde.make.A.html)

- n.repl:

  The maximum replicate index, in the sense used in
  [`INLA::inla.spde.make.A()`](https://rdrr.io/pkg/INLA/man/inla.spde.make.A.html).

- weights:

  Optional scaling weights to be applied row-wise to the resulting
  matrix.

## Functions

- `input_eval()`: **\[deprecated\]** from `2.12.0.9023`. Use
  [`bru_input()`](https://inlabru-org.github.io/inlabru/reference/bru_input.md)
  instead.

- `evaluate_inputs()`: **\[deprecated\]** since version `2.12.0.9023`.
  Use
  [`bru_input()`](https://inlabru-org.github.io/inlabru/reference/bru_input.md)
  instead. Computes the component inputs for included components for
  each observation model.

- `gmap()`: Plot a map using extent of a spatial object

  **\[deprecated\]** This function is deprecated as `ggmap` isn't
  supported.

  Used `ggmap::get_map()` to query map services like Google Maps for a
  region centered around the spatial object provided. Then calls
  `ggmap()` to plot the map.

  This function required the `ggmap` package.

- `gm()`: **\[deprecated\]** This function is deprecated as `ggmap`
  isn't supported.

  ggplot geom for spatial data

  gm is a wrapper for the
  [gg](https://inlabru-org.github.io/inlabru/reference/gg.md) method. It
  will take the first argument and transform its coordinate system to
  latitude and longitude. Thereafter,
  [gg](https://inlabru-org.github.io/inlabru/reference/gg.md) is called
  using the transformed data and the arguments provided via `...`. gm is
  intended to replace gg whenever the data is supposed to be plotted
  over a spatial map generated by gmap, which only works if the
  coordinate system is latitude/longitude.

- `ibm_linear()`: Deprecated alias for
  [`ibm_as_taylor()`](https://inlabru-org.github.io/inlabru/reference/ibm_as_taylor.md).

- `bm_mesh_B()`: **\[deprecated\]** Old deprecated name for
  [`bm_reparam()`](https://inlabru-org.github.io/inlabru/reference/bm_reparam.md)

- `bru_mapper_mesh_B()`: **\[deprecated\]** Deprecated name for
  `bm_mesh_B`

- `row_kron()`: Row-wise Kronecker products **\[deprecated\]** in favour
  of
  [`fmesher::fm_row_kron()`](https://inlabru-org.github.io/fmesher/reference/fm_row_kron.html).

  Takes two Matrices and computes the row-wise Kronecker product.
  Optionally applies row-wise weights and/or applies an additional 0/1
  row-wise Kronecker matrix product.

  Returns a
  [`Matrix::sparseMatrix`](https://rdrr.io/pkg/Matrix/man/sparseMatrix.html)
  object.
